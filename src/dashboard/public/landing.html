What's inside: modules, one switch each.

Every feature comes individually wrapped. Open one to see its commands and the settings it ships with; switch it on with /module enable or one click on the dashboard, and whatever you leave off stays out of your way.

Serving suggestion: tune it on the dashboard.

Log in with Discord, pick a server, and every module's options are there: channels, roles, messages, limits and schedules. These are four real Levels settings with the defaults they ship with. Change them and the preview shows what Frost.Byte would post.

Directions

  1. 1

    Add Frost.Byte

    Invite the bot to a server where you have Manage Server.

  2. 2

    Switch on modules

    Run /module enable tickets, or flip the module's switch on the dashboard. Setup commands work before a module is on.

  3. 3

    Fine-tune on the web

    Log in with Discord and set channels, roles, messages and limits for each module. Type /help in your server to see what you can use there.
