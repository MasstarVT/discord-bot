Instructions for use

Every module, its settings with the defaults they ship with, and all slash commands with who can run them. It's built from the bot's own module list and command files, so it matches what's in your server.

Contents

Getting started

  1. Add Frost.Byte to a server where you have Manage Server: invite the bot. Its slash commands appear on their own.
  2. Switch on the modules you want. Run /module list to see them all and /module enable <name> to turn one on, or flip its switch on the dashboard. A module's setup command works while the module is still off, so you can configure it first.
  3. Fine-tune on the web. Log in to the dashboard with Discord, pick the server, and set channels, roles, messages and limits for each module.
  4. Check what members see. /help lists only the commands that member can run and that are switched on.

Who can run what

Everyone
Any member, in a server where the command's module is on.
Moderators
Members with the moderator permissions the command asks for, or a moderator role set with /modconfig.
Admins
Members with Manage Server. Discord hides these commands from everyone else, and the bot checks again.

Core commands

These belong to no module and are always on.
